Rolling Robot

Project Overview

Design and construction of a hamster ball mechatronics project featuring autonomous navigation and control systems. This project demonstrates advanced robotics programming and mechanical engineering integration.

Project Details

  • Type: University Mechatronics Project
  • Duration: 8 weeks
  • Role: Lead Engineer & Programmer
  • Tools: Arduino, C++, CAD Software, 3D Printing

Key Features

  • Autonomous navigation within spherical constraint
  • Sensor integration for obstacle detection
  • Custom mechanical drive system
  • Real-time control algorithms
  • Wireless communication capabilities

Technical Challenges

The main challenge was developing a control system that could maintain stability and directional control within the spherical hamster ball. This required sophisticated balance algorithms and precise motor control to achieve smooth movement.

Engineering Solutions

Implemented a gyroscopic stabilization system combined with accelerometer feedback to maintain orientation. The drive mechanism uses differential wheel speeds to control direction while maintaining the robot's position within the ball.

Results

Successfully demonstrated autonomous navigation through obstacle courses with 90% accuracy. The project received top marks for innovation and technical execution, showcasing the integration of mechanical design with advanced control systems.
